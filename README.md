# GnanaSai Portfolio

Portfolio website of Gnana Sai, 3D technical artist. Built with [Astro](https://astro.build).

## Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Installs dependencies                       |
| `npm run dev`     | Starts local dev server at `localhost:4321` |
| `npm run build`   | Builds the site to `./dist/`                |
| `npm run preview` | Previews the build locally                  |

## Editing content

- **Projects:** `src/content/threeDProjects/*.md`, with images in `public/`
- **Social links and email:** `src/data/socialLinks.js`
- **Tools and project types:** `src/data/softwares.js`, `src/data/porjectTypes.js`
